# Change Impact Log

> 当前 Cycle 的 Change 记录模板。小型 Task 若仍在已确认 Scope 内且没有改变已确认契约，可以只在 Task 中记录增量；改变已通过 Gate 的内容、用户行为、约束或 Release 条件时，必须补全本记录。
> 本记录不替代 Decision、Stage Artifact、Gate 或验证结果。

## Artifact Contract

- Purpose：记录 Change 的影响范围、路由和最小验证集合。
- Inputs：当前有效的 Scope、Decision、Artifact、Registry 和 Signal / Evidence。
- Outputs：可追踪的 Change、受影响 Stage / Artifact、验证计划和 Release 影响。
- Acceptance Criteria：最早受影响 Stage、受影响闭包、可复用内容和必需验证均已明确；不确定范围已采用保守验证。
- Current Status：填写当前 Change 状态。
- Blocking Decisions：填写 `DEC-XXX` 或 `None`。
- Next Stage：填写 Router 指定的最早受影响 Stage。
